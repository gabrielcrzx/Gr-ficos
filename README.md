# Gráficos
Repositório para ospedar o código dos gráficos que calculam valor médio, fazem gráficos de linhas, pizza, etc.

O gráfico de Linhas mostra o volume de trabalho, revelando quantos milhões de procedimentos de urgência cada região realizou. O de Barras indica o custo médio, quanto o SUS, em média, gastou por cada um desses atendimentos. O de Pizza revela o quanto de dinheiro que cada região recebeu do governo.
